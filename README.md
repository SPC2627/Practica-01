# Práctica 01

Aquí tenemos la primera práctica, que es una introducción a los entornos de programación.

## Este es el repositorio donde se encontrarán las prácticas y este el archivo README.md del repositorio.

Un README es el nombre que se le pone a los archivos de texto de "presentación" de un repositorio o un programa. Normalmente son archivos de texto simple (con extensión .txt), pero en GitHub usamos archivos en lenguaje MarkDown (con extensión .md). El MarkDown es un lenguaje para crear texto que permite introducir algo de estilo (titulos, listas, negrita, cursiva, etc. y hasta ecuaciones) de lo que carecen los archivos .txt.
En GitHub es normal presentar los repositorios con README.md ya que la consola de GitHub es capaz de interpretar el estilo dado en el archivo MarkDown.

Para trabajar con las prácticas tendréis que "forkear" este repositorio en vuestro cuenta de GitHub y abrir los archivos a través de Google Colab. De este modo, cuando guardéis vuestros cambios a través de Google Colab, estos se guardarán en vuestra propia rama del repositorio.
